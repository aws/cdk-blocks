# create-blocks-app

Create an [AWS CDK Blocks](https://github.com/aws/cdk-blocks#readme) app:

```bash
npm create blocks-app@latest my-app
```

`npx create-blocks-app my-app` does the same.

This package is the unscoped name of [`@aws-cdk-blocks/create-blocks-app`](https://github.com/aws/cdk-blocks/tree/main/packages/create-blocks-app#readme). It runs that CLI with the arguments you give it, and each release depends on the same version of it. All options and templates are the same:

```bash
npm create blocks-app@latest my-app -- --template react
npm create blocks-app@latest -- --help
```

See the [`@aws-cdk-blocks/create-blocks-app` README](https://github.com/aws/cdk-blocks/tree/main/packages/create-blocks-app#readme) for the full documentation.
